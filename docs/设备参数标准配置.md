# Tomatis 设备参数 - 标准配置

## 📋 设备实际参数（Tomatis_D 录音）

### 录音说明
- **源文件**: `Tomatis_D.flac`
- **输入**: `D MNF.flac`（原始音频）
- **问题**: 前 16 秒是其他音乐，需要裁剪

### 设备参数设置

| 参数 | 设备值 | 说明 |
|------|--------|------|
| **音量** | 100 | 系统音量 |
| **门控 (Gate)** | 50 | UI 标尺值 |
| **延迟/提前** | 无 | 无延迟无提前 |
| **通道1 (C1)** | +5, -5 | 低频 +5dB, 高频 -5dB |
| **通道2 (C2)** | -5, +5 | 低频 -5dB, 高频 +5dB |
| **中心频率** | 1000 Hz | 0dB 支点 |
| **增益 (坡度)** | 12 dB/oct | 倾斜速度 |
| **平衡** | L:100, R:100 | 左右均衡 |
| **空气传导** | 100 | - |
| **骨传导** | 100 | - |

## 🎯 对应的软件参数

### 基础参数（已匹配）
```powershell
--fc 1000           # 中心频率 1000Hz ✓
--slope 12          # 坡度 12 dB/oct ✓
--c1_low 5          # C1 低频 +5dB ✓
--c1_high -5        # C1 高频 -5dB ✓
--c2_low -5         # C2 低频 -5dB ✓
--c2_high 5         # C2 高频 +5dB ✓
```

### Gate 参数（需要校准）

**设备**: Gate = 50

**当前映射**: 
```
T_dBFS = gate_scale * gate_ui + gate_offset
T_dBFS = 1.0 * 50 + (-74.2) = -24.2 dBFS
```

**校准方法**:
1. 对比 `Tomatis_D.flac` 和 `D_MNF_tomatis_v13.flac`
2. 分析 C1/C2 切换时刻的差异
3. 调整 `gate_offset` 使切换行为一致

### 延迟参数

**设备**: 无延迟无提前

**软件默认**: 
```powershell
--up_delay_ms 250   # C1→C2 延迟 250ms
```

**建议**: 如果设备真的是"无延迟"，应该设置：
```powershell
--up_delay_ms 0     # 无延迟
```

## 🔬 校准工作流程

### 步骤 1: 裁剪 Tomatis_D 前 16 秒

```python
import soundfile as sf

# 读取
x, sr = sf.read("Tomatis_D.flac", dtype='float32')

# 裁剪前 16 秒
cut_samples = int(16.0 * sr)
x_cut = x[cut_samples:]

# 保存
sf.write("Tomatis_D_cut16s.flac", x_cut, sr, subtype='PCM_24')

print(f"原始长度: {len(x)} 采样点 ({len(x)/sr:.2f} 秒)")
print(f"裁剪后: {len(x_cut)} 采样点 ({len(x_cut)/sr:.2f} 秒)")
```

### 步骤 2: 对齐并对比

使用现有的 `analyze_dbfs.py` 对齐 `D MNF.flac` 和 `Tomatis_D_cut16s.flac`，生成：
- `dbfs_tomatis_device.csv` - 设备实际输出的 dBFS
- `dbfs_tomatis_device.png` - 对比图

### 步骤 3: 分析 Gate 切换点

```python
import pandas as pd
import numpy as np

# 读取设备输出和软件输出
df_device = pd.read_csv("dbfs_tomatis_device.csv")
df_software = pd.read_csv("state_v13.csv")

# 找出切换点
def find_switches(df, threshold=3.0):
    df['out_diff'] = df['tomatis_dbfs'].diff().abs()
    switches = df[df['out_diff'] > threshold]
    return switches

device_switches = find_switches(df_device)
print(f"设备切换次数: {len(device_switches)}")
print(f"软件切换次数: {len(df_software[df_software['state'].diff() != 0])}")
```

### 步骤 4: 拟合 Gate 映射

```python
# 假设我们找到了多个 gate_ui 值和对应的阈值
gate_ui_values = [40, 50, 60]
threshold_dbfs = [-20.5, -24.2, -28.0]  # 从实测得出

# 线性拟合
from scipy.stats import linregress
slope, intercept, r, p, se = linregress(gate_ui_values, threshold_dbfs)

print(f"gate_scale = {slope:.3f}")
print(f"gate_offset = {intercept:.3f}")
print(f"R² = {r**2:.4f}")
```

## ⚙️ 参数调整指南

### 如果 C2 太多（软件比设备更"亮"）
→ 提高 gate_offset（例如 -70 而不是 -74.2）

### 如果 C2 太少（软件比设备更"厚"）
→ 降低 gate_offset（例如 -78 而不是 -74.2）

### 如果切换太频繁
→ 增大 hyst_db（例如 6 而不是 3）

### 如果切换延迟不对
→ 调整 up_delay_ms（设备说"无延迟"，建议设为 0）
